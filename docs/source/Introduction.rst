.. module:: H2MMburts

Introduction
============

The ``H2MMbursts`` module is an add-on to `smfbursts` that interfaces it with 
`H2MM_C <https://h2mmpythonlib.readthedocs.io/>`_ for analysis of burst based data with 
mutli-parameter photon-by-photon hidden Markov modeling (mpH:sup:`2` MM).

Install with 

.. code-block:: bash

   pip install H2MMbursts


or 

.. code-block::

   conda install H2MMbursts -c conda-forge
